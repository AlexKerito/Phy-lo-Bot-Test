Este es mi primer bot de discord!
Phylo-Bot

Tiene funciones tales como:
hello: El bot da un saludo
heh: El bot se rie, el usuario debe introducir la cantidad de risas
Saludo: Una funcion de saludo para español
Suma: Bot suma 2 numeros introducidos por el usuario
Contraseña: El bot genera una contraseña random
DatoRandom: Bot genera un dato random sobre sí mismo o el creador (yo!)
roll: Imprime Tail o Head
mem: Envia imagenes, estas puedes modificarlas en el archivo de Images
furry: Envia una imagen de esta comunidad
createtxt: Crea un bloc de notas con el texto mencionado
CalculateBlock: Calcula la cantidad de bloques de plástico que puedes crear de 20x10x30cm, se debe usar metros cúbicos
Reto: Desafio sobre el reciclaje
contaminacion: Envia imagenes de contaminación

Modificación sencilla, libre de modificar
